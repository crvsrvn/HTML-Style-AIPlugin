HTML 样式规范

html-style 插件模板 · v1.1.0

这一页本身就是模板：字体、版心、右侧大纲、图表交互由 hs-style 与 hs-script 提供，其余可读性增强全部是原生 HTML / CSS。

1.字体与版心#

正文 Comic Sans MS 16px，行高 1.75。版心固定 988px，在大纲左侧的区域内水平居中；页面底色浅色 #FCFCFB、深色 #151515。

2.图表#

图表放进 .hs-zoom；figure 直接包含的图片、SVG、canvas 会被自动包进去。按 F 或双击进入全屏，Esc 退出。

3.原生可读性增强#

3.1术语与提示#

版心
正文所在的固定宽度区域。
TOC
右侧大纲，可筛选，随滚动高亮当前章节。

重点句可以用 高亮；脚注用原生弹层，不需要脚本。

原生 popover 属性配合 popovertarget 按钮即可开合，点击空白处或按 Esc 关闭。

注意：能用原生 HTML / CSS 实现的交互，不要再写脚本。
