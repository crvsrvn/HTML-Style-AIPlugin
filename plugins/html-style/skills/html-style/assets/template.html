HTML 样式规范

html-style 插件模板 · v1.0.0

这一页本身就是模板：字体、版心、右侧大纲、图表交互全部由上方的 hs-style 与下方的 hs-script 提供。新页面复制这两块，然后只替换 <main class="hs-doc"> 里的内容。

字体与字号

正文使用 Comic Sans MS，16px，行高 1.75。设备上没有 Comic Sans 时依次回退到 Comic Neue、Chalkboard SE，中文字符回退到系统中文字体。

版心与大纲

内容区固定 760px 并水平居中。视口不小于 1240px 时，大纲停在版心右侧；更窄时收进右上角的「大纲」按钮，从右侧滑出。

大纲由脚本从 h2、h3 生成；需要收录 h4 时，给 main 加 data-toc-levels="2,3,4"。

图表交互

所有图表都放进 .hs-zoom 视窗。figure 直接包含的图片、SVG、canvas 会被自动包进去。

代码与引用

<figure>
  <div class="hs-zoom"><img src="diagram.svg" alt="状态机结构"></div>
  <figcaption>状态机结构</figcaption>
</figure>

链接使用 Claude 桌面版的强调蓝，例如 claude.ai。
